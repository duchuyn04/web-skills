# Sources: the real screens behind the kit and each recipe

The kit is not invented. Each choice follows what most real SaaS apps do, read from screens curated on Mobbin
(https://mobbin.com). Mobbin screens are references to look at, not files to copy: no image or code from them is in
this skill. When a project needs a screen no recipe covers, find real screens of that kind first (Step 2 of
SKILL.md) and follow the majority, the same way.

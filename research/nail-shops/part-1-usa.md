Owner ethnicity (for example Vietnamese-owned) could NOT be verified from the sites, so no shop is labelled that way. ## Common patterns noticed

- Header nav: Services / Menu & Prices / Gallery / Locations / Gift Cards / Book Now (sticky, high-contrast button). Boutique chains add Shop, Memberships, Press, Franchise, Careers.
- Home section order: hero (photo or short video loop + tagline + Book Now) -> service category cards (with "from $" price) -> gallery / Instagram grid -> about / values (non-toxic, vegan, sterilised tools) -> reviews (Google badge, named quotes) -> locations with hours + parking -> footer (policy, FAQ, gift cards).
- Service categories repeat: Manicure, Pedicure, Nail Enhancements (Gel-X, builder gel, acrylic, dip), Russian manicure, Nail Art, Waxing, Lashes/Brows, Facials/Head spa, Add-ons.
- Pricing structure: itemised menu grouped by category, "from $" entry prices, add-on list (nail art, removal, French tips, paraffin, callus), a named premium tier (VIP / collagen / spa pedicure). Anchors seen: classic mani $30 / gel $45, pedi from $49, Russian from $60, Gel-X $87, custom art $80 (Luxo, Chicago); services from $50 (NAILaCARTE).
- Booking is almost always an embedded or linked third party: Square Appointments, Vagaro, Fresha, Booker, Zenoti, Mangomint, Boulevard. Multi-location brands give one Book button per location.
- Trust signals: Google rating badge, named review quotes, "non-toxic / 10-free / vegan / cruelty-free", sterilisation statement, 24h cancellation policy, press logos.
- Extras: gift cards (very common), memberships / loyalty (Kitchen Nail Bar, NAILaCARTE, Dear Sundays), referral or first-visit discounts, group bookings / private events, retail shop (polish, press-ons).
- Visual styles: (1) luxury editorial = serif headings (Playfair, Cormorant, Italiana) + neutral/cream/black; (2) playful nail-art = pastel / rainbow, rounded display font; (3) local-SEO templates (WordPress/Elementor/Wix) with Roboto/Open Sans and address in the title.
- Gallery trend: filter chips (All / Minimal / Chrome / Nail art) and "Book this look" on each image (Brisa) is a strong template feature.
- Local SEO: title pattern "Best Nail Salon in <Neighborhood>, <City> <ZIP>" and NAP (name, address, phone) repeated in header and footer.

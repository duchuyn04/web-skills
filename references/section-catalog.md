# Section catalog

Generated by `scripts/make_catalog.py` from each `templates/sections/*/schema.json`. Do not edit by hand.

Every section in page.json is `{"type": "<variant>", "data": {...}}`. Optional keys next to type: `id` (anchor, lowercase) and `tone` (light, muted or dark). Leave both out unless you have a reason.

Accent markup: in fields marked "text with *accent*", wrap 1-4 words in asterisks to color them, for example `"Support teams that *protect your CSAT*"`. Use it once per title.

## Page-level fields

These sit at the top of page.json, next to `sections`.

- `archetype`: text 3-40 chars
- `preset`: text 3-40 chars
- `lang`: one of en, vi, ja, ko, de, fr, es, pt, zh (optional, default "en")
- `site`: object
  - `brand`: text 2-32 chars
  - `brand_mark`: text 1-3 chars (optional)
  - `logo`: image key or path (optional)
  - `title`: text 20-70 chars
  - `description`: text 70-170 chars
- `theme`: object (optional)
  - `primary`: hex color (optional)
  - `accent`: hex color (optional)
  - `accent_2`: hex color (optional)
- `features`: object (optional)
  - `magnetic_cta`: true/false (optional, default false)
- `override_order`: object (optional)
  - `reason`: text 20-300 chars
